# Protocolo SISC

Este documento define inicialmente las áreas que deberá especificar el protocolo.

- Identidad de usuarios
- Formato de mensajes
- Cifrado
- Autenticación
- Intercambio de claves
- Firmas digitales
- Archivos adjuntos
- Gestión de dispositivos
- Revocación de claves
- Recuperación de cuenta
- Versionado del protocolo
