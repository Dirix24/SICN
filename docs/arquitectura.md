# Arquitectura SISC

## Flujo principal

El mensaje se prepara y cifra en el dispositivo del remitente.

El servidor recibe datos cifrados y los almacena o transporta.

El destinatario autorizado recibe los datos y los descifra localmente.

## Componentes

- Core
- Cliente
- Servidor
- Criptografía
- Extensión
- Protocolo
- Gestión de claves
