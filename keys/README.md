# keys/

Carpeta reservada para material de ejemplo relacionado con claves (por
ejemplo, capturas o huellas digitales de muestra para la documentación).

**Importante:** ninguna clave privada real debe guardarse aquí ni en
ningún otro lugar del repositorio. Las claves privadas de cada usuario se
generan y almacenan cifradas localmente en su directorio de datos
(`SICN_DATA_DIR`, por defecto `sicn_data/identity.enc`), que está excluido
del control de versiones mediante `.gitignore`.
