# files/

Carpeta reservada para adjuntos de ejemplo o material de referencia no
sensible del proyecto (por ejemplo, capturas de pantalla para la
documentación).

No es la carpeta donde el cliente guarda los archivos recibidos: eso
ocurre en el directorio de datos local del usuario (por defecto
`sicn_data/received/`, configurable con la variable de entorno
`SICN_DATA_DIR`), que está excluido del control de versiones (ver
`.gitignore`) porque contiene contenido descifrado del usuario.
